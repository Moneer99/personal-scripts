# 🎂 Age Calculator Script

A simple Bash script to calculate your exact age and the time remaining until your next birthday.

This script supports different input formats such as `YYYY M D` or `YYYY MMDD`.

---

## Requirements

- Bash
- No external dependencies

---

## Usage

1. Make the script executable:
```bash
chmod +x age.sh
```

### Run the script
```bash
./age.sh
```

### Enter your birth date when prompted:

Enter your birth date (e.g., 1995 5 7 or 1995 0521):


### Input Examples

1995 5 7
1995 0521
2005 128


### Example Output

If the input is

2005 128


The output will be:

------------------------------------

Your Birthday Date: 2005-12-08
🎂 Your current age is: 20 years old

------------------------------------

🎂 Exactly age is:
   20 Years, 1 Months, and 3 Days

------------------------------------
📅 Remaining until your next birthday:
   10 Months and 27 Days
------------------------------------
